# Security and privacy

The site stores volunteers' voices and e-mail addresses, so security problems are privacy problems too.

## Reporting a vulnerability

Please do not open a public issue. Report it privately with GitHub's
[Report a vulnerability](https://github.com/brunopacheco1/quenya-voices/security/advisories/new) form, under the
*Security* tab of this repository. Say what you found, how to reproduce it, and what data it could expose.

You will get an answer as soon as possible. If the problem exposed personal data, the project will handle it as
a personal data breach under the GDPR, including telling the volunteers affected and the supervisory authority
when the law requires it.

## Your own data

To download or delete your own recordings and account, use *My data* on the site. For any other request about
your personal data, use the contact in the site's Privacy Notice.

## Supported versions

Only the version currently deployed, which is the latest `main`, is supported.
